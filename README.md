# ArmaVault - Firearm Models Directory App

A mobile application built with Flutter that serves as a **Firearm Models Directory** with full CRUD operations and third-party API integration.

## Third-Party APIs Used

1. **Wikipedia API**

   * URL: [https://en.wikipedia.org/api/rest_v1/page/summary/](https://en.wikipedia.org/api/rest_v1/page/summary/)
   * Purpose: Search and fetch firearm model information and images

## Custom REST API

* URL: (http://armavault.duckdns.org/armavault.php)
* Full CRUD operations for firearm model records

## Features

* View list of firearm models
* Add new firearm model
* Auto-fetch firearm details from Wikipedia
* Auto-fetch firearm model images
* Edit existing firearm model information
* Delete firearm models with confirmation dialog
* Search firearm models
* Display firearm details such as manufacturer, country, firearm type, caliber, and action type
* Animated splash screen

## Tech Stack

* **Framework:** Flutter
* **Backend:** PHP REST API
* **Database:** MySQL via Freehostia
* **API Integration:** Wikipedia REST API
* **Domain:** DuckDNS
